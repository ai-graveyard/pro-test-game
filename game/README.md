# 能打职业吗你？ v1.4.0

一个零依赖、手机全屏的 3D 网页小游戏。六关分别在独立的立体场景中操作，支持单指点击、鼠标和键盘。直接打开 `index.html`，或用任意静态服务器托管 `game/` 即可运行。

## v1.4.0 更新

- 六关改为独立 3D 实战场景，场景中直接呈现闸门、能量靶、护盾、无人机、机库、哨塔和拆弹装置。
- 新增 `stage-engine.js`，负责原生 WebGL 几何渲染、透视投影和 Canvas 回退；`stage-scenes.js` 定义六个场景及目标拾取；`stage-styles.css` 提供关卡视口、状态与操作 HUD。
- `stage-art.js` 为六关提供完整工业环境，`stage-models.js` 提供分层装甲、枪管、引擎、炮塔底座、手套、线缆和机械开关等精细部件。
- 视口铺满关卡，提示采用前置 HUD；射击机位移近主体，纵深警戒区在手机上采用三列布局。引擎增加倒角、圆柱、三维纹理字牌、接触阴影及实例合批。
- 判断关改为红色尖翼敌机开火、蓝色带十字友机停火；警戒关改为直接点中入侵哨塔，并支持方向键选择后按空格射击。
- 警戒关每轮限时 2200ms，速度评分锚点更新为 350/500/750/1000/1800ms；其他关卡的评分锚点保持不变。
- 进入操作关卡后暂停 `arena3d.js` 背景训练场，返回说明页或结果页后恢复，减少重复 GPU 绘制。
- WebGL 不可用或上下文丢失时，Canvas 回退保留六关的立体投影、目标变化与哨塔拾取。
- 开火加入枪声、枪口闪光、短弹道和后坐力；命中伴随金属撞击声、火花、碎片及目标受击动作。
- 格挡加入盾牌震荡、冲击环和断刃，完美格挡有独立提示音；拆弹加入压杆、解锁和断电动画，成功与失败使用不同声音。
- 音效由本地 Web Audio 合成，首次操作时启用。顶部可随时静音并保存偏好；切到后台立即停止。没有背景循环或隐藏计时提示，反馈均在输入判定后触发。
- 按小工具构建规范 1.8.0 补齐 ES2017 解析门禁、Chrome 61 CSS 基线、Flex 间距行为检测、原生 Storage 优先与旧缓存迁移，以及 WebGL 资源预算和自动降级。

## 当前六关规则

| 关卡 | 场景、输入与计时规则 |
| --- | --- |
| 神经反射 | 走廊闸门解锁后亮起绿色能量靶，立即点击开火。3 次有效测试，随机等待；抢跑重试并扣分，绿靶亮起 5 秒未开火则本关超时。 |
| 完美格挡 | 能量刃从远处迎面飞来，点击格挡使其在接触前方护盾时被拦截。3 轮、速度不同，接触时刻为每轮 `duration × 0.78`。 |
| 别急着点 | 识别机库中的无人机：红色尖翼敌机点击开火，蓝色带十字友机忍住。共 10 个随机排列信号，5 次敌机、5 次友机。 |
| 预判射击 | 运输机在移动到一半时进入蓝色机库，之后失去视野；预判其穿过右侧出口准星的时刻开火。3 轮、速度随机；进入遮挡前开火按提前处理，超过到达时刻 650ms 未开火则 MISS。 |
| 多目标警戒 | 按 4、6、9、12 座哨塔逐轮增加目标数。某座哨塔变红并展开武器后，必须在 2200ms 内直接点中它；提前开火、点错和超时均计 MISS。键盘方向键循环选择，空格或回车射击。 |
| 黄金 6.66 | 核心装置的实体 LED 数码屏开始计时，在最接近 6.66 秒时点击拆弹。只有 1 次机会，4.00 秒后数值隐藏；10.00 秒仍未拆弹则失败并显示最终时刻。 |

除多目标警戒需要点中实体目标外，其他五关点击测试视口任意位置即可操作。操作结果在各自场景内冻结或反馈，随后进入单关结果页。

## 渲染文件

```text
index.html        # 本地入口与脚本、样式加载顺序
mini-compat.js    # Chrome 61布局基线、Flex间距检测和可视高度
mini-storage.js   # 版本判断、平台Storage、缓存预载与旧数据迁移
arena3d.js        # 首页、说明页和结果页的背景训练场
stage-engine.js   # WebGL 几何、相机、投影和 Canvas 兼容回退
stage-art.js      # 地板、装甲墙、管道、机柜、货架与工业道具
stage-models.js   # 可复用武器、无人机、哨塔、护盾和拆弹台
stage-scenes.js   # 六个 3D 场景、目标状态与警戒关拾取
stage-styles.css  # 大幅关卡视口、上下方 HUD 和响应式布局
game-audio.js     # 手势解锁、本地合成音效、静音与声音生命周期
impact-feedback.js # 即时闪光、命中标记、冲击环与短震动
impact-styles.css # 打击反馈与音效开关样式
styles.css        # 其他页面的布局与霓虹美术
game.js           # 流程、输入、单调时钟、评分、存档与分享
```

关卡状态通过 `startAt`、`duration`、目标索引等参数传给场景。`requestAnimationFrame()` 负责按当前时间绘制，操作判定与渲染共享时间和位置参数；输入发生时按实际时间冻结并重绘，避免用 CSS 动画近似计分。警戒关的可点击区域来自当前相机对哨塔的投影，Canvas 回退复用相同的投影和拾取逻辑。

## 为什么从 8 关缩减为 6 关

首版顺序：神经反射、完美格挡、别急着点、预判射击、多目标警戒、黄金 6.66。

移除两关：

- 接棍挑战：与完美格挡都在测试时机，且竖屏高度差异会放大下落距离和速度的设备偏差。
- 极限闪现：90–120ms 的显示窗口高度依赖刷新率和浏览器调度，与神经反射、多目标警戒也有较强重叠。

轮数也按移动端短局调整，完整体验目标为 80–110 秒。五维报告仍覆盖反应、判断、时机、预判和专注；黄金 6.66 以停表误差作为判断与抗压的复合指标。

## 实现约束

- 所有交互优先使用 `pointerdown`。
- 所有计时使用 `performance.now()`。
- 六关场景由 `requestAnimationFrame()` 绘制；完美格挡、预判射击和黄金 6.66 依据共享的起始时间与真实 elapsed time 计算位置或秒表。
- 游戏态使用 `100dvh`，页面禁止滚动和选中文字，计分输入只处理主要指针。
- 安全区同时兼容真机 `env()` 与 PC 模拟器注入的 `--safe-area-inset-*` 变量。
- 顶部额外预留小红书原生返回与分享按钮的控制区净空。
- 仅在关卡实际操作阶段使用顶部预留区显示当前关卡名称，首页、说明页与结果页不重复显示。
- 结果页使用原生 SVG 五维雷达图，无外部图表依赖。
- 页面切换、重开与后台切换都会清理 timeout 和 animation frame。
- 3D 训练场与关卡使用原生 WebGL。评分逻辑位于 `game.js`，场景与判定共享状态参数；WebGL 不可用或上下文丢失时提供 Canvas 立体投影回退，保留目标拾取。
- 兼容系统 `prefers-reduced-motion` 设置，减少非必要的背景运动；关卡目标的实际运动和即时提示继续保留。
- 打击反馈独立于评分时钟；减少动态效果时关闭后坐、震动和扩散位移，保留简短颜色反馈。浏览器不支持音频时，全部玩法与视觉反馈仍可运行。
- 进入应点击状态后不会无限等待：神经反射在绿色出现 5 秒仍未点击时自动跳过本关并记最低成绩；格挡、敌我识别、预判和警戒均有短于 5 秒的处理窗口，拆弹以 10 秒为上限。
- 黄金 6.66 的计时数字会在 4.00 秒隐藏；10.00 秒仍未点击时判定失败，并重新显示 `10.00` 后按最低成绩计入。
- 客户端 9.46+ 优先通过平台 Storage 保存进度和静音偏好，启动等待缓存预载；旧客户端与普通浏览器分别使用 `sessionStorage` 和 `localStorage`。读取失败按新会话处理，写入失败保留当前内存状态而不宣称已持久化；切到后台只重置当前关。
- 普通按钮和测试视口支持触屏、鼠标、空格和回车；警戒关使用实体目标点选，键盘用方向键循环选择，再按空格或回车射击。
- 无后端、无外部图片、无网络字体、无第三方依赖。

## 严格评分锚点

所有时间类指标采用分段线性评分，超过最末锚点归零：

- 神经反射：100ms=100、200ms=80、300ms=60、400ms=30、500ms=0。
- 判断反应：180ms=100、220ms=80、260ms=60、340ms=30、450ms=0。
- 完美格挡：20ms=100、45ms=80、80ms=60、140ms=30、220ms=0。
- 预判射击：40ms=100、80ms=80、140ms=60、240ms=30、400ms=0。
- 多目标警戒：350ms=100、500ms=80、750ms=60、1000ms=30、1800ms=0。
- 黄金 6.66：30ms=100、80ms=85、200ms=60、350ms=30、600ms=0；超过 200ms 显示 MISS。

判断关正确 10/9/8/7/6 次分别获得 100/85/65/40/20 的正确率基础分；专注关点中 4/3/2 个入侵哨塔分别获得 100/60/25 的命中基础分，不再提供高额保底分。

神经反射每次抢跑会从该维度扣除 10 分，最低为 0 分。反应与识别计时在浏览器绘制帧中同步渲染目标后开始，避免把 DOM 重建耗时算进用户反应。

## 分享到小红书

完成全部测试后，点击“分享到小红书”，页面会在本地 Canvas 生成一张 3:4 成绩卡，优先用 `writeTempFile` 转为本地文件，再通过 `window.xhs.miniTool.postNote` 打开小红书图文笔记发布页。标题、成绩文案和图片会自动预填，用户仍可在发布前编辑。

- 分享内容只在本地生成，不发起网络请求。
- 非小红书小工具环境不会调用未定义能力：分享会优先使用系统分享，保存会提示在小红书小工具中操作。
- 保存成绩卡会调用 `window.xhs.miniTool.writeTempFile` 与 `saveImageToPhotosAlbum`，首次使用可能弹出系统相册权限请求。
- 从原生发布页返回时保留最终成绩，不会强制重新测试。

## 小工具交付验证边界

源码静态检查、ES2017 解析、离线体积审计和普通浏览器开发回归不代表小工具已验收。请将最终 ZIP 上传创服平台，在平台模拟器完成全部六关、音效、恢复、保存与分享验证，再对同一产物分别使用 Android 真机和 iOS 真机扫码验证。Chrome 61 / Android 8.1 的实际兼容性和真机帧率、内存尚未实测。
