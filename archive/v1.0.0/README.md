# 能打职业吗你？ v1.0.0

一个零依赖、手机全屏、只需单指点击的网页小游戏。直接打开 `index.html`，或用任意静态服务器托管本目录即可运行。

## 为什么从 8 关缩减为 6 关

首版保留：神经反射、别急着点、完美格挡、预判射击、多目标警戒、黄金 6.66。

移除两关：

- 接棍挑战：与完美格挡都在测试时机，且竖屏高度差异会放大下落距离和速度的设备偏差。
- 极限闪现：90–120ms 的显示窗口高度依赖刷新率和浏览器调度，与神经反射、多目标警戒也有较强重叠。

轮数也按移动端短局调整，完整体验目标为 80–110 秒。五维报告仍覆盖反应、判断、时机、预判和专注；黄金 6.66 以停表误差作为判断与抗压的复合指标。

## 实现约束

- 所有交互优先使用 `pointerdown`。
- 所有计时使用 `performance.now()`。
- 完美格挡、预判射击和黄金 6.66 使用 `requestAnimationFrame()`，按真实 elapsed time 计算位置或秒表。
- 游戏态使用 `100dvh`，禁止滚动、缩放、选中文字和多指操作。
- 安全区同时兼容真机 `env()` 与 PC 模拟器注入的 `--safe-area-inset-*` 变量。
- 顶部额外预留小红书原生返回与分享按钮的控制区净空。
- 仅在关卡实际操作阶段使用顶部预留区显示当前关卡名称，首页、说明页与结果页不重复显示。
- 结果页使用原生 SVG 五维雷达图，无外部图表依赖。
- 页面切换、重开与后台切换都会清理 timeout 和 animation frame。
- 无后端、无图片、无网络字体、无第三方依赖。

## 严格评分锚点

所有时间类指标采用分段线性评分，超过最末锚点归零：

- 神经反射：100ms=100、200ms=80、300ms=60、400ms=30、500ms=0。
- 判断反应：180ms=100、220ms=80、260ms=60、340ms=30、450ms=0。
- 完美格挡：20ms=100、45ms=80、80ms=60、140ms=30、220ms=0。
- 预判射击：40ms=100、80ms=80、140ms=60、240ms=30、400ms=0。
- 多目标警戒：200ms=100、260ms=80、340ms=60、500ms=30、700ms=0。
- 黄金 6.66：30ms=100、80ms=85、200ms=60、350ms=30、600ms=0；超过 200ms 显示 MISS。

判断关正确 10/9/8/7/6 次分别获得 100/85/65/40/20 的正确率基础分；专注关发现 4/3/2 个目标分别获得 100/60/25 的命中基础分，不再提供高额保底分。

## 分享到小红书

完成全部测试后，点击“分享到小红书”，页面会在本地 Canvas 生成一张 3:4 成绩卡，并通过 `window.xhs.miniTool.postNote` 打开小红书图文笔记发布页。标题、成绩文案和图片会自动预填，用户仍可在发布前编辑。

- 分享内容只在本地生成，不发起网络请求。
- 非小红书小工具环境不会调用未定义能力，页面会提示用户回到小红书内分享。
- 从原生发布页返回时保留最终成绩，不会强制重新测试。
